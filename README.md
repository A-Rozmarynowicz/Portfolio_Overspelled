## About the project
"Overspelled" is a large-scale, interdisciplinary, hobby project. Though still under development, this commercial video game is a result of two years, or over 1 500 hours of programming, drawing, researching, testing, brainstorming, failing, and starting over, to name a few.

**"Overspelled" demo is now available for free on Steam! You can view the store page and play the demo here:
[https://store.steampowered.com/app/3425570/Overspelled/](https://store.steampowered.com/app/3425570/Overspelled/)**


Development time: from 04.2024 to 07.2027 (expected).

## Why don't I share source files?
'Overspelled' is a commercial project, thus I don't share the files.

## Technologies used
Programming language:
- GDScript (similar to Python)

Game engine:
- Godot

Tools:
- git
- Steamworks:
    - cloud integration, branches, demos, betas, and other systems.

Graphics and sound editing tools:
- Aseprite
- Audacity
- OBS Studio
- DaVinci Resolve
- GIMP

No help of Generative Artificial Inteligence was used during the development, in particular, coding or creating the art.
